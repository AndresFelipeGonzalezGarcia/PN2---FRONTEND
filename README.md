# PN2---FRONTEND
Interfaz web del sistema de programación de horarios de clases desarrollado para Proyecto Núcleo 2 (2026-2), Universidad El Bosque, Facultad de Ingeniería — Ingeniería de Sistemas.

Este repositorio contiene la interfaz para dos perfiles de usuario:

Coordinador Académico: visualiza la malla generada, ajusta con drag-and-drop, revalida colisiones y publica.
Estudiante: consulta grupos publicados y se matricula validando cupo y cruces de horario.

Repositorios relacionados

1. pn2-frontend (este repo):	Interfaz web
2. pn2-backend:	API REST, motor de asignación, RBAC
3. pn2-database: scripts y migraciones
